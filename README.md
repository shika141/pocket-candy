# 今日一顆糖

版本：`09－替換糖果分類九種口味圖標`

這是可直接部署的靜態網站完整原始碼。將 `dist` 設為網站根目錄即可，不需要後端或建置步驟。

## 本版修改

- 將「糖糖的糖果分類表」中九種口味原本的 Emoji，換成使用者提供的角色插畫。
- 圖片依口味一一對應：草莓、檸檬、葡萄、牛奶、水蜜桃、薄荷、焦糖、巧克力、棒棒糖。
- 調整分類卡片圖標尺寸、陰影與手機版顯示。
- 保留抽取畫面原有插畫、糖紙冊愛心糖紙圖案及收藏詳情功能。

## 檔案結構

- `dist/index.html`：完整程式與介面
- `dist/assets/guide/`：糖果分類九款口味角色圖
- `dist/assets/candy/`：抽取結果與收藏詳情插畫
- `dist/assets/wrappers/`：糖紙冊九款愛心糖紙圖案
- `dist/assets/candy-background.jpeg`：主背景

收藏紀錄保存在瀏覽器的 `localStorage`，更新不會清除先前收藏。
