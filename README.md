# 《今日一顆糖》v12

曾巟糖の非科學糖果占卜。此版本重新整理全站字體系統，保留第 11 版的所有版面、圖片、動畫、互動與瀏覽器本機紀錄。

## 字體配置

- 英文標題：Fredoka
- 中文標題：芫荽（Iansui）
- 正文：jf open 粉圓（Huninn）
- 糖糖小字與角色台詞：小賴字體（Xiaolai）

## 使用方式

這是純靜態網頁專案。可直接部署整個資料夾，或在資料夾內執行：

```bash
python3 -m http.server 8080
```

再開啟 `http://localhost:8080`。

字體由線上字體服務載入，第一次開啟時需要網路連線。

## 資料保存

收藏與上次抽取紀錄儲存在瀏覽器的 Local Storage。清除網站資料或更換瀏覽器／裝置後，紀錄不會自動同步。
