# 《今日一顆糖》v11

曾巟糖の非科學糖果占卜。此版本將首頁「點糖罐抽取」按鈕原本的糖罐 Emoji，替換為使用者提供的水彩玻璃糖果罐圖案。

## 本次修改

- 首頁抽糖糖罐改用 `assets/candy-jar.webp`
- 保留點擊抽糖、手機搖一搖、按壓與晃動動畫
- 保留糖紙冊、糖果分類、歷史紀錄與既有糖果圖案

## 使用方式

這是純靜態網頁專案，可直接開啟 `index.html`，或將整個資料夾部署到任一靜態網站服務。

為避免瀏覽器對本機檔案的限制，建議在資料夾內啟動簡易 HTTP 伺服器，例如：

```bash
python3 -m http.server 8080
```

再開啟 `http://localhost:8080`。

## 資料保存

收藏與上次抽取紀錄儲存在瀏覽器的 Local Storage。清除網站資料或更換瀏覽器／裝置後，紀錄不會自動同步。
