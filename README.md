# 今日一顆糖

版本：`07－修正糖紙冊仍顯示 Emoji`

這是可直接部署的靜態網站完整原始碼。將 `dist` 設為網站根目錄即可，不需要後端服務或建置步驟。

## 本版修正

- 修正按下「糖紙冊」後仍呼叫舊版顯示函式、導致收藏卡繼續顯示 Emoji 的問題。
- 糖紙冊現在會實際顯示九款對應口味的愛心糖紙圖案。
- 保留既有收藏資料格式，更新後不會清除先前紀錄。
- 保留抽糖揭曉插畫、糖果背景、手機搖一搖與所有原有互動。

## 口味圖標

草莓、檸檬、葡萄、牛奶、水蜜桃、薄荷、焦糖、巧克力、棒棒糖皆有獨立對應圖案。

## 檔案結構

- `dist/index.html`：完整程式與介面
- `dist/assets/candy-background.jpeg`：主背景
- `dist/assets/candy/`：抽糖結果與動畫插畫
- `dist/assets/wrappers/`：糖紙冊九款口味圖標

收藏紀錄保存在瀏覽器的 `localStorage`。同一裝置與瀏覽器再次開啟時會保留；清除網站資料或更換裝置後不會自動同步。
