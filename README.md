# 今日一顆糖

版本：`08－新增糖紙收藏詳情與放大檢視`

這是可直接部署的靜態網站完整原始碼。將 `dist` 設為網站根目錄即可，不需要後端或建置步驟。

## 本版新增

- 糖紙冊中的每張收藏卡都可點選。
- 點開後以放大視窗回看當天完整抽選內容。
- 詳情包含日期、糖果插畫、糖運、可信度星級、糖籤、糖糖台詞與今日小行動。
- 若當天獲得額外牛奶糖，也會在詳情內保留顯示。
- 詳情最下方顯示該口味對應的完整愛心糖紙圖案。
- 收藏卡加入「點開回看」提示及滑鼠、鍵盤操作狀態。

## 檔案結構

- `dist/index.html`：完整程式與介面
- `dist/assets/candy-background.jpeg`：主背景
- `dist/assets/candy/`：抽糖結果與詳情插畫
- `dist/assets/wrappers/`：糖紙冊九款口味圖標

收藏紀錄保存在瀏覽器的 `localStorage`。更新不會清除先前收藏；同一裝置與瀏覽器再次開啟時仍會保留。
