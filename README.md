# 今日一顆糖

版本：`06－替換糖紙冊九種口味圖標`

這是可直接部署的靜態網站完整原始碼。打開 `dist/index.html` 即可在本機預覽，也能將 `dist` 資料夾部署到任何靜態網站服務。

## 本版修改

- 將「我的糖紙冊」內原本的 Emoji 圖標，換成九款使用者提供的愛心糖紙插畫。
- 圖案依口味一一對應：草莓、檸檬、葡萄、牛奶、水蜜桃、薄荷、焦糖、巧克力、棒棒糖。
- 保留第 05 版的九款抽糖揭曉插畫。
- 保留第 04 版糖果背景、手機搖一搖、每日紀錄與糖紙冊本機保存功能。

## 檔案結構

- `dist/index.html`：完整程式與介面
- `dist/assets/candy-background.jpeg`：主背景
- `dist/assets/candy/`：抽糖結果與動畫插畫
- `dist/assets/wrappers/`：糖紙冊九款口味圖標

## 部署

將 `dist` 目錄設定為網站根目錄即可，不需要後端服務或建置步驟。

收藏紀錄保存在瀏覽器的 `localStorage`，因此同一裝置、同一瀏覽器再次開啟時，仍會保留上次的糖紙冊紀錄。清除瀏覽器網站資料或更換裝置後，紀錄不會自動同步。
