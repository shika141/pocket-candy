# 今日一顆糖・第 16 版

本版新增「電腦版左側糖糖探頭彩蛋」。糖糖會緊貼瀏覽器左側，像從螢幕外探頭；手機與窄螢幕不顯示。

## 部署

- GitHub Pages：可直接使用專案根目錄的 `index.html` 與 `assets/`。
- Cloudflare Pages 等平台：可把輸出目錄設成 `dist`。
- 更新時請完整覆蓋所有檔案，包含根目錄與 `dist`，避免舊快取或錯誤發布目錄仍顯示上一版。

## 本版重點

- 新增真正透明背景的 `assets/tangtang-peek-v16.png`。
- 只在寬度至少 1100px、具滑鼠游標的桌面環境顯示。
- 圖片不攔截點擊，不影響抽糖、糖紙冊與糖果分類操作。
- 支援「減少動態效果」系統設定。
