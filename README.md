# 今日一顆糖・第 27 版

本版將音樂開關換成使用者提供的兩張音符圖案，並縮短歌曲標題。

- 左上角品牌名稱下方只顯示《ひとくちラッキー！》。
- 播放時顯示粉藍雙八分音符；關閉時顯示粉彩靜音音符。
- 點擊音符圖案可隨時關閉或恢復背景音樂。
- 音樂以低音量循環播放，切到背景分頁時暫停，返回頁面後恢復。
- 網站會記住使用者上次的音樂開關選擇。
- 若瀏覽器阻擋自動播放，第一次點擊或操作頁面後便會開始。

- 每天第一次產生新抽取結果時，播放糖糖伸手進糖罐並抽出糖果的 GIF。
- GIF 每次會從第一幀重新播放，完整播放約 3.15 秒後才揭曉結果。
- 當天再次開啟網頁時，直接顯示當日抽到的糖果與糖籤。
- 當天收起結果後再次點糖罐，也不會重播糖糖小動畫。
- 隔天第一次重新抽取時，動畫會再次播放。
- 保留一天一次抽取、手機搖一搖、糖紙冊與所有既有紀錄。

部署時請完整覆蓋根目錄與 `dist` 資料夾。
