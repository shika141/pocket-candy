# 今日一顆糖・第 20 版

本版將糖紙冊改為同口味合併收藏，並保留每次抽取的日期與籤文。

## 收藏規則

- 每天仍然只能隨機抽取一次。
- 隔天可以再次隨機抽到相同糖果。
- 相同口味會合併成一張收藏卡，顯示 `×1`、`×2`、`×3` 等數量。
- 點開收藏卡後，會依日期列出每次的糖籤編號、籤文、糖糖解籤與今日小行動。
- 現有糖紙冊紀錄會直接沿用，不需重新收藏。

## 部署

- GitHub Pages：使用根目錄的 `index.html` 與 `assets/`。
- Cloudflare Pages：可將發布目錄設為 `dist`。
- 更新時請完整覆蓋根目錄與 `dist`。
